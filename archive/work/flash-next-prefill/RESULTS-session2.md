## The arm names, decoded

| tag prefix | what it is |
|---|---|
| `base-r366`, `txt-gather` | unmodified r366 delivery: pool tier, `GGML_SCHED_DEVGATHER` default (gather) |
| `force`, `opt`, `opt2`, `gather-v4` | gather arms (with the op-timing / census instrumentation) |
| `stage`, `stage16k`, `stage-v4`, `stage-slots16` | `GGML_SCHED_DEVGATHER=0` = the ring, filled by the two-tier kernel; **the pre-patch slow path** |
| `ctl-a/b`, `fix-a/b` | the `moe_cache_stage_ready` arena-stand-down gate, off/on |
| `bulk-a`, `bulk48`, `bulk-ref` | `MOE_HOST_POOL_STAGE_BULK=1`: one copy-engine DMA of the whole table from the pool mirror |
| `dma-gap`, `kern-2tier` | `MOE_HOST_POOL_STAGE_BATCH=0/1`: the per-expert DMA / the two-tier kernel |
| `h36/h47/h48-*` | the hybrid (`BULK=2`): coalesced host run DMAs + one kernel for the arena side |
| `r48-*`, `r47-redir` | the slot ping-pong (`GGML_SCHED_STAGE_REDIRECT`), in place vs `=0` (copy) |
| `nc30/33/36/38/40`, `ub16k/24k/32k` | `-ncmoe` / `-ub` sweeps; every `ub > 16384` arm is an OOM |
| `ah0/ah1` | `GGML_SCHED_STAGE_AHEAD=0/1` (the scheduler lookahead) |
| `*mib*`, `pin0` | `MOE_EXPERT_CACHE_MIB` / `MOE_HOST_POOL_PIN` arms |

## Reproduce

```sh
cd wip/flash-next-prefill
./arm.sh TAG MOE_EXPERT_HEATMAP=load NCMOE=48 GGML_SCHED_DEVGATHER=0        # the best known arm
./arm.sh TAG MOE_EXPERT_HEATMAP=load NCMOE=48 GGML_SCHED_DEVGATHER=0 \
         MOE_HOST_POOL_STAGE_BULK=1                                         # A/B: whole-table DMA
./arm.sh TAG MOE_EXPERT_HEATMAP=load NCMOE=48 GGML_SCHED_DEVGATHER=0 \
         GGML_SCHED_STAGE_REDIRECT=0                                        # A/B: copy instead of in-place
./arm_gpu.sh TAG 0 <same env>                                               # + rocm-smi (GPU use/clocks)
```
