# Python string and collection utilities

Write one complete, self-contained, production-quality Python file that implements every item below,
in order. Use type hints throughout, give every public function a concise docstring, and finish with an
`if __name__ == "__main__":` block containing assertions that exercise each item.

1. `def tokenize(text: str) -> list[str]:` split on whitespace while preserving quoted phrases
   (single or double quotes) as single tokens, and honour a backslash escape inside quotes.
2. `def stable_frequencies(items: list[str]) -> dict[str, int]:` returning counts whose insertion order
   follows first appearance in `items`.
3. `class Trie:` prefix tree with `insert(word)`, `contains(word)`, `starts_with(prefix)`, and
   `complete(prefix, limit)` returning up to `limit` completions in lexicographic order.
4. `def wildcard_match(pattern: str, text: str) -> bool:` supporting `?` (one character), `*` (any run
   including empty) and `[abc]` / `[a-z]` classes. Raise `ValueError` on an unclosed class.
5. `def levenshtein(a: str, b: str, max_distance: int | None = None) -> int:` with an early exit when
   the distance provably exceeds `max_distance`.
6. `class RollingHash:` polynomial rolling hash over a byte string with `append`, `digest`, and
   `index_of(pattern)` returning the first matching offset or `-1`.
7. `def group_anagrams(words: list[str]) -> list[list[str]]:` grouping by a canonical key while keeping
   the input order stable within each group.
8. A small `argparse` CLI at the bottom with subcommands `match`, `lev` and `anagrams` that exercise
   items 4, 5 and 7 respectively.

Write the code now. Do not explain it in prose beyond the docstrings.
