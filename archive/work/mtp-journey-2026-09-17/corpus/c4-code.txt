# Python systems, files and concurrency

Write one complete, self-contained, production-quality Python file that implements every item below,
in order. Use type hints throughout, give every public class and function a concise docstring, and
finish with an `if __name__ == "__main__":` block containing assertions that exercise each item.

1. `class AtomicFile:` a context manager writing to a temporary sibling file and renaming over the
   target on clean exit, with an explicit `rollback()` and `fsync` before the rename.
2. `def safe_join(root: str, *parts: str) -> str:` joining paths while refusing any component that
   escapes `root`, resolving symlinks and raising `ValueError` otherwise.
3. `class ThreadPool:` a fixed-size worker pool with `submit(fn, *args)` returning a `Future`-like
   object exposing `result(timeout)`, and a `shutdown(wait)` that drains cleanly.
4. `class TokenBucket:` a monotonic-clock rate limiter with `acquire(n, blocking)` and a `capacity`
   constructor argument; document the clock source and why it is monotonic.
5. `def tail_lines(path: str, n: int) -> list[str]:` returning the last `n` lines without reading the
   whole file, handling files without a trailing newline.
6. `class LineReader:` an iterator over a file that yields logical records spanning an explicit
   continuation marker, with a bounded buffer and a clear error on an unexpected end of file.
7. `def retry(times: int, base_delay: float, jitter: float) -> callable:` a decorator retrying on a
   supplied exception tuple with exponential back-off and full jitter.
8. A small `argparse` CLI at the bottom with subcommands `tail`, `join` and `retry` that exercise
   items 5, 2 and 7 respectively.

Write the code now. Do not explain it in prose beyond the docstrings.
