# A combinatorial derivation

Derive, step by step, with every intermediate result justified, and state the reasoning explicitly at
each stage. Do not skip algebraic steps. Present the final closed forms at the very end.

A conference runs 9 distinct talks over 3 parallel tracks on each of 5 days. Each track runs 3 talks per
day, and no talk is repeated across tracks or days. A committee must choose a subset of talks to record.

Work through the following in order:

1. Count the number of ways to choose 4 talks so that:
   (a) no two are on the same day;
   (b) no two are in the same track;
   (c) the 4 talks include exactly one from each of the first two days and two from the remaining days.
   Derive an expression, then simplify it to a single integer.

2. Count the number of ways to seat all 9 talks of a single day into a 3x3 arrangement so that:
   (a) each track occupies one column;
   (b) no talk with an odd index is adjacent (orthogonally) to another talk with an odd index.
   Explain the inclusion-exclusion steps in full.

3. Prove that for every positive integer n, the number of ways to tile a 2 x (2n+1) board with 1 x 2 and
   2 x 2 tiles is divisible by 3.

4. Derive a recurrence for the number of valid 4-talk selections described in part 1 when the conference
   has d days and t tracks per day, each running k talks per day, and solve it when d = t = k = n.

5. Finally, verify each of your closed forms at n = 1 and n = 2 by explicit enumeration, show the
   enumerations, and state plainly whether the formulas agree.
