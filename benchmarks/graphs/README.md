# v2 graphs (llama-benchy suite, 2026-08-27)

Generated by `scripts/make-v2-graphs.py` from the raw JSON in
`results/benchy/` (no hardcoded numbers). 16 charts, split by KV cache
type so each compares the three backends (master / boosts / vulkan) at a
single KV type — 3 series per chart, not 6, so the tight decode cluster is
legible.

Conventions:
- **Colors**: red = master, amber = boosts, blue = vulkan.
- **Line style**: solid = f16 KV, dashed = bf16 KV (so the f16 and bf16
  charts of a given set line up when viewed side by side).
- **Depth axis**: sqrt-scaled, labeled with the real context depth
  (0K/4K/8K/16K/32K/64K/128K). The depths are heavily non-linear; sqrt
  spreads the shallow anchors while keeping the deep end readable.
- **Prefill**: y origin at 0 (wide range). **Decode**: zoomed y-window
  (the span is ~17-30 t/s depending on set) so the ~1% backend separation
  is visible instead of crushed against 0; the master-bf16 collapse and
  the multi-card vulkan collapse both still fit within the window.

## The story in four charts

- `v2-tg-1Q6-bf16.png`: the headline. master-bf16 decode collapses
  (22.1 -> 8.99 t/s, -48%); boosts and vulkan both hold ~18 t/s. The
  upstream BF16 decode penalty, and the fork's fix.
- `v2-tg-3c-bf16.png`: boosts dominates 3-card decode (~39 t/s); master
  collapses to 16.5; vulkan is stuck near the bottom (multi-card
  layer-split sync, ~11-16 t/s). Boosts beats vulkan ~2.5x on decode.
- `v2-tg-1Q4-f16.png`: the crossover. boosts beats vulkan at every depth
  on Q4_K_XL (where block 10's VDR boost is strongest) - the opposite of
  Q6_K, where vulkan's launch latency edges it ahead ~1%.
- `v2-tg-1Q6-f16.png`: the mirror. on Q6_K (weaker VDR boost) vulkan
  edges boosts by ~1% at every depth; both above master.
