## Verdict

* **Gate rule 1 (acceptance): PASS.**  Pos-1 acceptance is `0.761-0.984` on every axis and both cache types,
  against a ~0.45 floor — nowhere near the `0.000` collapse the 2026-09-02 regression produced.
* **Gate rule 2 (MTP must not lose to plain): PASS, strongly.**  `draft-mtp` is 1.97×-4.42× plain on every axis,
  and the *prose* axis — the one the rule allows to be within 10 % — is 2.85-3.07×.
* **Gate rule 4 (purity `n_max <= 7`): PASS.**  `--spec-type none` and `draft-mtp` generated **byte-identical
  text on all four axes, on both cache types** (eight pairs).  This is the property a decode/verify regression
  breaks first, and it holds at the strict 3-device `-sm tensor` shape.
* **Rule 3 (determinism vs the previous release) is not claimed here**: these hashes are this build's, and the
  cross-build comparison at this shape lives in `GREEDY-PURITY.md` (the r319/tile-FA width work) and in the
  re-base's own prefill-logit record (`WORKLOG.md` 261121.005: KLD 0.000000 against an r327-recorded base).

Rates are 3-device `-sm tensor` Q8_0 with the adaptive ceiling at the delivery default (7).  Do not compare them
with the older 2-GPU Q8_0 table in the methodology (a different split shape; that table also predates the adaptive
controller's tuning), and do not read a launch-order-sensitive percentage out of a single run — each cell is one
run at `-n 3000`.
