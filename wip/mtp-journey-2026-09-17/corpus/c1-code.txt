# Python implementation tasks

Write one complete, self-contained, production-quality Python file that implements every item below,
in order. Use type hints throughout, give every public class and function a concise docstring, and
finish with a `if __name__ == "__main__":` block containing assertions that exercise each item.

1. `class LRUCache:` a thread-safe least-recently-used cache with O(1) `get` and `put`, a `maxsize`
   constructor argument, and `__len__` / `__contains__` support. Use `collections.OrderedDict` and a
   `threading.RLock` for synchronisation.
2. `class UnionFind:` union-find with path compression and union by rank. Provide `find`, `union`
   (returning whether a merge happened), `connected`, and a `groups()` helper that returns the
   component members as a list of lists.
3. `def dijkstra(graph: dict[str, list[tuple[str, float]]], start: str) -> dict[str, float]:`
   computing single-source shortest paths over an adjacency list. Handle unreachable nodes by leaving
   them out of the result.
4. `class RingBuffer:` a fixed-capacity byte buffer with `write`, `read(n)`, `peek(n)`, `available`,
   and `free` methods. Writes that would overflow must return the number of bytes actually stored.
5. `def topo_sort(graph: dict[str, list[str]]) -> list[str]:` Kahn's algorithm. Raise `ValueError`
   on a cycle, naming one of the nodes still involved.
6. `class Matrix:` immutable 2-D float matrix with `__matmul__`, `__add__`, `__sub__`, `transpose`,
   `determinant` (LU with partial pivoting), and `inverse` (raising `ValueError` on a singular
   input). Include `__repr__` and `__eq__`.
7. `def merge_sorted(a: list[int], b: list[int]) -> list[int]:` plus a `timed` decorator that prints
   the wall-clock duration of the decorated call and returns the original result.
8. A small `argparse` CLI at the bottom that can exercise the LRU cache and the union-find from the
   command line, with subcommands `lru` and `uf`.

Write the code now. Do not explain it in prose beyond the docstrings.
