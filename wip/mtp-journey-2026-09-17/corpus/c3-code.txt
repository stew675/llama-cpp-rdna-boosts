# Python algorithms and dynamic programming

Write one complete, self-contained, production-quality Python file that implements every item below,
in order. Use type hints throughout, give every function a concise docstring, and finish with an
`if __name__ == "__main__":` block containing assertions that exercise each item.

1. `def knapsack(weights: list[int], values: list[int], capacity: int) -> int:` 0/1 knapsack maximising
   value. Use a one-dimensional rolling array and document the iteration order in a comment.
2. `def coin_change(coins: list[int], amount: int) -> int | None:` fewest coins summing exactly to
   `amount`, or `None` if impossible. Return the coin multiset as well via a companion function
   `coin_change_used`.
3. `def edit_script(a: str, b: str) -> list[str]:` reconstructing the shortest edit script as a list of
   operations such as `"ins 3 x"` or `"del 5"`, using dynamic programming plus backtracking.
4. `def longest_increasing_subsequence(xs: list[int]) -> list[int]:` returning the actual subsequence,
   not just its length, in O(n log n).
5. `def tarjan_scc(graph: dict[int, list[int]]) -> list[list[int]]:` strongly connected components in
   reverse topological order; document the recursion-vs-iteration choice.
6. `def a_star(start: str, goal: str, neighbours: callable, heuristic: callable) -> list[str] | None:`
   returning the path, with a tie-break on insertion order so results are deterministic.
7. `def subset_sum_count(xs: list[int], target: int) -> int:` number of subsets summing to target, with
   a memory-bounded implementation and a comment on the modulus if one is used.
8. A small `argparse` CLI at the bottom with subcommands `knap`, `lis` and `scc` that construct small
   examples inline and print the results.

Write the code now. Do not explain it in prose beyond the docstrings.
