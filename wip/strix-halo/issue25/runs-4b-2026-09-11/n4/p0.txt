## 1. Internal Working of a Hash Map

### Hash Function
A hash function maps keys to integer indices within the hash table array. A good hash function:
- Distributes keys uniformly across the array.
- Minimizes collisions.
- Is fast to compute.

### Collision Handling
When two keys hash to the same index, a collision occurs. Common strategies include:

- **Chaining**: Each array slot contains a linked list (or other structure) of elements with the same hash.
- **Open Addressing**: When a collision occurs, search for the next available slot using techniques like linear probing, quadratic probing, or double hashing.
